# LogWatch / ForestryDocket

Web application developed during the Patch Summer Accelerator to replace paper-based timber dockets in Irish forestry logistics.

The project aimed to make timber transport records easier to create, store, and retrieve by moving the docket workflow into a simple digital system.

## Features

- Digital timber docket creation
- Supabase-backed data storage
- Basic user-facing web interface
- Hosted prototype built for demo-day presentation
- Designed around forestry logistics workflows

## Tech stack

- JavaScript
- Supabase
- AWS
- HTML/CSS
